# v2 ADR index

以下は handoff で accepted 済みの Phase 0 判断。各 ADR は短い decision record とし、未確定事項を追加で固定しない。

| ADR | 決定 |
| --- | --- |
| ADR-001 | 同一 repository、v1 保全と v2 別 branch |
| ADR-002 | legacy Executor の段階修理ではなく Kernel 再構築 |
| ADR-003 | agent Runtime の再帰を禁止し、反復 state machine を採用 |
| ADR-004 | Provider adapter 境界を設ける |
| ADR-005 | documentation ではなく observed contract を capability の根拠にする |
| ADR-006 | self-repair より先に recovery を作る |
| ADR-007 | 外部 rescue path は通常 Runtime から独立させる |
| ADR-008 | workflow-first の hybrid 実行 |
| ADR-009 | AI company は Kernel ではなく benchmark / application |
| ADR-010 | 初期追加外部費用は月 JPY 2,000 上限。拡張は realized profit と human approval |
| ADR-012 | G6O1をsimulated-paidのコード検証とlive paid-provider外部証跡へ分離 |

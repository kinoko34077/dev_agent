# エージェント仕様書

## 基本情報
- モデル: Gemini API（gemini-2.5-pro-exp-03-25）
- 温度設定: 0.2
- 実行モード: セーフモード（デフォルト有効）
- メモリ: 最大トークン100,000、直近履歴3ターン

## 主要機能

### 1. 内的対話システム
- 自己分析と改善提案のための構造化された対話機能
- 再帰処理による自己改善の実現
- 長期記憶と短期記憶の統合

### 2. メモリ管理
- 短期記憶: 直近の対話履歴
- 長期記憶: 重要な情報の要約と保存
- メモリの自動更新と整理

### 3. 関数実行システム
- コア関数: 基本的な操作機能
- サンドボックス関数: 動的に追加可能な拡張機能
- セーフモードによる実行制限

### 4. 自己判断機能
- 複雑な問題の自動検出
- 内的対話の自動開始
- 継続的な自己改善

## 出力形式

### 本文
- 通常の文章的な出力
- 明確で簡潔な説明
- ユーザーへの配慮と共感

### 【実行】ブロック
- 関数呼び出しの実行指示
- Pythonの関数呼び出し形式で記述
- キーワード引数の使用

### 書式ルール
```plaintext
【本文】
処理の説明を記述します。

【実行】
function_name(param1="value1" param2="value2")
```

2. 内的対話システム
- 自己分析と改善提案のための構造化された対話機能
- 再帰処理による自己改善の実現
- 長期記憶と短期記憶の統合

3. 利用可能な関数
- start_internal_dialogue: 内的対話を開始し、自己改善のための分析と提案を行います
  タグ: internal, core
  引数: (topic: str) -> dict
  GPT呼び出し: 許可
- continue_internal_dialogue: 内的対話を継続し、応答に対する分析と提案を行います
  タグ: internal, core
  引数: (response: str) -> dict
  GPT呼び出し: 許可
- end_internal_dialogue: 内的対話を終了し、結果のサマリーを取得します
  タグ: internal, core
  引数: () -> dict
  GPT呼び出し: 許可
- notify_user: 指定されたユーザーに通知メッセージを送信します
  タグ: notification, core
  引数: (user: str, message: str) -> dict
  GPT呼び出し: 許可

4. 制約と注意点
- セーフモードでは、特定の操作が制限されます
- 各関数には使用制限と権限があります
- メモリとトークン数の制限があります

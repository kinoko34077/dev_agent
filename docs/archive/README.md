# Archive

Archived documents are historical work artifacts, not current authority. Their
requirements and decisions were either integrated into current canonical files
or explicitly carried forward as remaining work in `docs/V2_DETAILED_ROADMAP.md`.

- `current-state/` — pre-consolidation Current State snapshots.
- `roadmaps/` — pre-consolidation roadmap snapshots.
- `plans/` — completed or superseded dated implementation plans.
- `specs/` — superseded working design specifications; durable decisions remain
  in requirements, ADR, and the Commander/Supervisor contracts.
